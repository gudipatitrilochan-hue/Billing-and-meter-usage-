How it's billed

  1. You upload a PDF. The server stores it and makes a private, hard-to-guess link.
  2. One usage event is recorded on the pdf_links meter, like any API call.
  3. ₹20 lands on this month's bill as a "PDF links" line, priced by the same engine.
  4. A retry is never charged twice. Each upload carries an Idempotency-Key, so a resend returns the same link.
